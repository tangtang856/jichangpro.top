Mac 程序员必备：终端 Terminal、Git 与 Homebrew 命令行代理终极配置

系统代理对 Mac 终端不生效？教您如何通过几行 alias 脚本一键开启终端代理，让 git clone 与 brew update 跑满千兆带宽。

📅 最新更新: 2026-03-08 📱 推荐核心: Terminal / Git / Brew ⏱️ 阅读时长: 约 6 分钟
💡 教程概要与前提

macOS 的系统代理默认不对 BSD 终端程序生效，开发者必须显式配置环境变量或使用 TUN 模式才能让命令行畅通无阻。

📋 教程步骤导览
  • 步骤 1 确认客户端本地监听端口
  • 步骤 2 在 zshrc 中添加一键开关脚本
  • 步骤 3 在终端随时一键开启

步骤 1：确认客户端本地监听端口

在当前运行的代理客户端（如 Clash Verge）中确认混合代理端口（默认通常为 7890）。

步骤 2：在 zshrc 中添加一键开关脚本

在终端输入 nano ~/.zshrc，在末尾追加如下内容：

alias setproxy="export http_proxy=http://127.0.0.1:7890; export https_proxy=http://127.0.0.1:7890; echo Proxy-on"
alias unsetproxy="unset http_proxy https_proxy; echo Proxy-off"
保存后执行 source ~/.zshrc。

步骤 3：在终端随时一键开启

每次在终端需要下载海外资源前，输入 setproxy 回车即可立即加速；输入 curl cip.cc 可查看当前终端出口 IP。

常见故障排查与答疑 (Troubleshooting)

Git 经常报错 LibreSSL SSL_connect: Connection reset by peer？
这是典型被墙拦截，输入 git config --global http.proxy http://127.0.0.1:7890 即可让 Git 专走代理。
