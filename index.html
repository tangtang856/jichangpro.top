什么是 IPLC 专线？
国际私有租用线路，完全绕过公网防火墙，零丢包、低延迟代表。
什么是 IEPL 专线？
国际以太网私有专线，具备高弹性和敏捷路由，目前高品质机场主流专线。
什么是 Clash 规则分流？
国内网站直连、海外网站走代理、局域网绕行，实现智能省流量不卡顿。
什么是 Hysteria2 协议？
基于魔改 UDP 的新型传输协议，专治弱网丢包，晚高峰暴力提速神兵利器。

❓ 常见问题答疑 (FAQ)

围绕用户最关心的网络加速、隐私安全与节点选购问题做出客观解答

什么是机场？它和传统的商业 VPN 有何区别？
“机场”是中文互联网对基于 Shadowsocks、V2Ray、Trojan、Hysteria2 等协议提供多节点代理加速服务商的通称。传统 VPN（如 ExpressVPN）采用全局加密流量特征明显，易被防火长城识别阻断；而机场节点通过流量伪装与国内多线 BGP/IPLC 专线转发，具备更强抗封锁能力与极低延迟。
为什么不同机场的价格差距很大？几元钱和数十元有何不同？
核心成本差距在于线路物理带宽。几元钱的廉价机场多采用廉价公网直连 VPS 虚拟化超卖，晚高峰丢包严重；数十元的专线机场租用三大运营商正规企业级 IPLC/IEPL 跨境物理光纤，不走公网防火墙，晚高峰依然能跑满千兆带宽。
访问 ChatGPT 或使用 Claude 总是报错怎么办？
OpenAI 与 Anthropic 对访问 IP 实行严苛的风控过滤，大批量共用的数据中心机房 IP 容易被识别并提示 1020 报错或限制登录。建议在本站“AI 专线”专题中挑选具备原生住宅 IP 分流的高质量专线节点。
为什么我们强烈建议“主力+备用”双机场策略？
即使是顶级专线机场，也可能因海底光缆割接或运营商突发故障导致临时断流。配置一家优质专线月付套餐作为主力，再搭配一家不限时按量付费套餐作为备用，能实现极端特殊时期的绝对网络可用性保障。
